    `func Collapse(raw string) string`: trim raw with strings.TrimSpace; if the trimmed value is
    empty, return "" immediately (ARTIST-03). Otherwise scan the trimmed string for the EARLIEST
    (lowest byte index) occurrence of any of these four delimiter substrings, checked via
    strings.Index for each and keeping the minimum non-negative index: a comma ",", a spaced hyphen
    " - " (space-hyphen-space, so it does not match names like "Jean-Pierre" that hyphenate without
    surrounding spaces), the literal " with " (space-with-space, case-sensitive — do not match bare
    "and" or "And" or "&" or ";", which must NOT trigger a split per the corpus), and a run of two
    consecutive spaces "  " (the double-space convention observed in the Karajan and Fitzgerald
    role-suffix corpus values). If none of the four delimiters are found, return the trimmed string
    unchanged. If one is found, return strings.TrimSpace of the substring before that delimiter's
    index. This single earliest-delimiter-wins rule is what makes every one of the four ROADMAP join
    conventions (comma, spaced hyphen, role suffix, with/orchestra) collapse correctly with one code
    path — do not special-case any of the four conventions separately, and do not add a
    hand-maintained exception map (see Task 1's Adderley note). Run gofmt and go vet on the new file.
  </action>
