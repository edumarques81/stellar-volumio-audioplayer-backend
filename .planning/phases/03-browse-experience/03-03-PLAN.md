<objective>
Wire the pure `discgroup` (03-01) and `dupebadge` (03-02) functions into the MPD-direct album-listing
code path — `Service.GetAlbums` (the cache-disabled/empty fallback) and `Service.GetArtistAlbums`
(which is ALWAYS MPD-direct; `CachedService` never overrides it, so this is the ONLY code path an
artist-albums request ever takes). Also define the shared wire-contract additions (`Album.Badge`,
`Album.DiscCount`, `Track.Disc`) that Plan 04 (cache wiring) depends on, and make `GetAlbumTracks`
disc-aware so a grouped multi-disc album's combined track list sorts correctly.

Purpose: This is the foundational "interface-first" plan for the phase's backend half — every later
backend plan (cache wiring, empty-state fallback, deploy) builds on the type additions and grouping
call-sites this plan establishes.

Output: `Service.GetAlbums` and `Service.GetArtistAlbums` return grouped, badged `Album` records;
`Service.GetAlbumTracks` returns correctly disc-sorted tracks for a grouped album's combined URI.
</objective>
