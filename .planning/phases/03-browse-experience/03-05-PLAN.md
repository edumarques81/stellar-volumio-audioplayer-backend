<objective>
Implement the defensive ARTIST-04/BROWSE-04 fallback: when `Service.GetArtistAlbums` resolves to zero
albums for a given artist, query MPD directly for any tracks crediting that artist (via the `Artist`
tag, independent of the `AlbumArtist` grouping the rest of the pipeline uses) and return them as a
playable `LooseTracks` list instead of a bare empty response.

Purpose: D-08 established that no artist in the live 45-artist library currently has zero albums —
Phase 1's retag fixed the one reported case (Karajan). This is defensive work, proven by a synthetic
fixture per D-09, not a live acceptance step (constraint G — do not plan an impossible live check).
The scenario is realistic: Phase 1 demonstrated untagged imports happen, and the backlogged file-
ingest feature (999.2) will make them more likely.

Output: `Service.GetArtistAlbums` never returns a response a client can only render as a dead end.
</objective>
